## `>` currently building

> Built for [**TLB-MilSim**](https://github.com/TLB-MilSim) — an Arma 3 milsim unit.
> These live in private org repos, so the links point at the org rather than at 404s.

<table>
<tr>
<td width="50%" valign="top">

### 🛰️ FASTER Web
**Arma 3 server management panel**

A web replacement for the FASTER WPF manager. Mod deployment via
SteamCMD + junction links, live A2S player tracking, attendance
rosters, scheduled auto-restarts with crash recovery, Discord
webhook alerts, and a bearer-token external API.

`Next.js 15` `TypeScript` `SQLite` `Tailwind`

</td>
<td width="50%" valign="top">

### 🚀 TLB Launcher
**Desktop modpack launcher**

Frameless Electron app with an NSIS installer and auto-update.
Discord OAuth login gated on unit membership role, live server
browser over A2S, one-click join, and full-auto modpack sync.

`Electron` `Express` `sql.js` `Discord OAuth`

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 📋 TLB Panel &nbsp;·&nbsp; QMS
**Ops tooling & qualifications**

A Python-backed unit panel plus an in-game qualification
management system written in SQF — tracking training, quals
and readiness across the unit.

`Python` `SQF`

</td>
<td width="50%" valign="top">

### 📊 MilSimReporter
**After-action reporting**

Turns raw operation logs into structured after-action reports
for post-op review.

`TypeScript`

</td>
</tr>
</table>
